# DM Elevators & Escalators

Premium vertical mobility engineering, architectural elevators, commercial escalators, and certified 24/7 AMC maintenance.

## Architecture
- **`frontend/`**: React, Vite, Tailwind CSS, Three.js 3D cabins, Lucide Icons
- **`backend/`**: Node.js & Express API for inquiries and service requests

## Local Development
```bash
# Run Frontend
npm run dev

# Run Backend
npm run dev:backend
```

## Production Build
```bash
npm run build
```
